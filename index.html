How Timetable Maker works

Four easy steps

  • 1Classes — add your subjects and time slots (UiTM students can import everything with a student ID).
  • 2Schedule — drag each class onto the day and time it happens.
  • 3Style — pick a background, and move the timetable to the top, middle or bottom.
  • 4Save — download the PNG, set it as your wallpaper, and save a backup file.

Handy tips

  • ✋Drag a placed class to move it. Pull its right edge to make it longer. Drop it on the red bar to remove it.
  • 📱On a phone, press and hold a class for a moment, then drag.
  • 🖼Want a cooler wallpaper? In Style, choose Photo and upload your own picture. Darken it or raise Card frost so the text stays easy to read.
  • 💾Your work autosaves in this browser. Use Save Timetable File for a backup you can load anywhere.
  • 🔒Private by design: nothing is uploaded. The only network request is the optional UiTM import.
